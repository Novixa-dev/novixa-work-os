1 نظرة عامة والهدف

يستبدل النظام الجداول المبعثرة والاشتراكات المتعددة بمساحة عمل واحدة تخص الشركة فقط (Single Workspace).

🎯

المشكلة

تشتّت المهام والعملاء والمعرفة بين أدوات متفرقة، وضعف في دعم العربية وRTL.

💡

الحل

نظام ويب داخلي يربط التنفيذ اليومي بالمشاريع والمنتجات وعلاقات العملاء مع سجل تدقيق كامل.

🚫

خارج النطاق (MVP)

المحاسبة، الرواتب، الحضور، الفوترة، بوابة العملاء العامة، بديل الدردشة، ذكاء اصطناعي مستقل.

2 الميزات والوحدات

كل عنصر ظاهر في الواجهة مرتبط بنقطة API حقيقية ومحمي بصلاحيات من جهة الخادم.

📊

لوحة التحكم

مؤشرات حيّة، المهام المتأخرة، «يومي»، تقدم المشاريع النشطة، متابعات العملاء، وآخر النشاطات.

✅

عملي (My Work)

يومي، مهامي، المتأخرة، المُسندة من قبلي — لتركيز شخصي سريع.

🗂️

المهام

عرض قائمة وكانبان، فلاتر، مهام فرعية، اعتماديات مع منع الدوران، تعليقات، ومرفقات خاصة.

🚀

المشاريع

دورة حياة المشروع، مسؤول، مراحل (Milestones)، تقدم محسوب تلقائياً من المهام، أرشفة.

📦

المنتجات

كتالوج منتجات نوڤيكسا (عقار، مُهاجم، Serve، Kitchen-POS) مع الأعمال المرتبطة.

🤝

العملاء وCRM

عملاء وجهات اتصال، سجل تفاعلات، متابعات، فرص بيع وتحويل الصفقة الرابحة إلى مشروع تسليم.

📚

قاعدة المعرفة

إجراءات تشغيل (SOP)، سجلات معمارية، أدلة تشغيل، وتهيئة الموظفين الجدد.

⚙️

الإعدادات والفريق

إدارة المستخدمين والأدوار، إعدادات المساحة، التفضيلات، الثيم واللغة والمنطقة الزمنية.

مزايا عابرة للوحدات

⌨️

لوحة الأوامر

Ctrl+K بحث شامل في المهام والمشاريع والمنتجات والعملاء والمعرفة بحسب الصلاحية.

🔔

الإشعارات

درج إشعارات مع تعليم كمقروء وتعليم الكل.

🌗

ثنائي اللغة والثيم

عربي RTL افتراضي وإنجليزي LTR، وضع داكن/فاتح، خطوط عربية مناسبة.

🧾

سجل التدقيق

تسجيل الدخول/الخروج، الرفع والتنزيل، التغييرات الحساسة.

3 حالات الاستخدام

الدورالسيناريوالنتيجة
عضو فريقيفتح «يومي» صباحاً، يغيّر حالة مهمة، يضيف تعليقاً ومرفقاً.تتحدّث نسبة تقدّم المشروع تلقائياً ويُسجَّل النشاط.
مدير مشاريعينشئ مشروعاً بمراحل، ويسند مهاماً ويربط اعتماديات.يمنع النظام الاعتماديات الدائرية.
مدير مبيعاتيسجّل اجتماعاً مع عميل ويحدد متابعة، ثم ينقل الفرصة إلى «رابحة» ويحوّلها إلى مشروع.مشروع تسليم مرتبط بالعميل والفرصة.
مدير النظاميضيف مستخدماً، يعطّل حساباً، يعدّل إعدادات المساحة.تُطبَّق الصلاحيات فوراً ويُدوَّن التدقيق.
ضيف (عميل)يدخل ليرى مهام مشروعه فقط.لا يصل إلى CRM ولا إلى بيانات غير مُسندة إليه (403).

7 التشغيل خطوة بخطوة

المتطلبات

Node.js 20+ · pnpm 10 · PHP 8.4 (≥ 8.4.1) مع pdo_sqlite وintl وmbstring · Composer 2.8+ (و Docker للتشغيل الإنتاجي).

أ) تشغيل محلي (الأسهل)

  1. استنساخ المستودع 
    git clone https://github.com/Novixa-dev/novixa-work-os.git
cd novixa-work-os
  2. تجهيز الخادم 
    cd apps/api
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve --port=8000
  3. تشغيل الواجهة (في نافذة طرفية ثانية) 
    cd apps/web
pnpm install
pnpm dev        # http://localhost:3000
  4. تسجيل الدخول بحساب ahmed@novixa.dev وكلمة المرور password123.
على ويندوز: يمكن استخدام .\scripts\setup.ps1 أو الأمر pnpm setup من الجذر.

ب) النشر على خادم (Docker)

انظر docs/DEPLOYMENT-PRODUCTION.md: صور docker/api وdocker/web وdeploy/compose.yml. ملف .env (مفتاح التطبيق وكلمة مرور قاعدة البيانات) يُولَّد على الخادم ولا يدخل Git.

10 الأمان

🛡️

تفويض من الخادم

Policies بمبدأ الرفض الافتراضي، وفحص كل سجل يُطلب (IDOR).

🔑

مصادقة

Rate limit، تعطيل الحساب، انتهاء الرموز، سياسة كلمة مرور، وإلغاء الرموز الأخرى عند التغيير.

📎

مرفقات خاصة

تخزين خاص بأسماء عشوائية، قيد الحجم/الصيغة، تنزيل بعد فحص الصلاحية، nosniff.

🧱

ترويسات الأمان

X-Frame-Options · Referrer-Policy · Permissions-Policy · HSTS على HTTPS.

تم إصلاحه: كان docker-compose.yml يحتوي APP_KEY وكلمة مرور قاعدة بيانات افتراضيتين مكتوبتين صراحةً. صارت قيماً إلزامية من .env. يُنصح بتدوير أي مفتاح استُخدم سابقاً.

12 القيود المعروفة والخطوات التالية

  • أمان الواجهة تحفظ رمز الدخول في localStorage؛ الأفضل الانتقال لكوكي HttpOnly عبر Sanctum SPA.
  • مواءمة الوثائق تذكر Nuxt 4 بينما المثبّت 3.21 — قرار ترقية أو تعديل الوثائق.
  • جودة رفع Larastan إلى المستوى 6 (18 ملاحظة أنواع مصفوفات)، وإضافة اختبارات Playwright للرحلات الحرجة.
  • منتج تعديل/حذف صفحات المعرفة، تصفّح (Pagination) للقوائم الكبيرة، وتغطية اختبار أوسع للتعليقات والمرفقات.
  • تشغيل مراقبة وتنبيهات، وتجربة استعادة النسخ الاحتياطي دورياً.
