* **Category:** Comprehensive Real Estate Operating System (B2B SaaS & Enterprise Source Code License).
* **Reference Showcase:** *دار حضرموت العقارية* (Dar Hadramout Real Estate).
* **Key Capabilities:**
  - Property and unit inventory management (residential, commercial, land plots).
  - Tenant database, electronic contracts, and lease expiration tracking.
  - Rental installment scheduling and collection receipts.
  - Maintenance request workflows and expense accounting.
  - Arabic-first RTL dashboards with multi-currency handling (YER, SAR, USD).

* **Category:** Automated Growth & Outbound Marketing Intelligence Engine.

### 2.3 Kitchen-POS & Novixa Serve

## 3. Organizational Structure & Team Roles

1. **Owner (المالك):** Executive oversight, product strategy, critical technical decisions, and financial approval.
2. **Administrator (مدير النظام):** Workspace configuration, user provisioning, security policies, and integrations.
3. **Manager / Project Lead (مدير المشاريع / قائد تقني):** Project planning, milestone scheduling, task assignment, and CRM pipeline management.
4. **Member / Senior Engineer / Designer (عضو فريق / مهندس / مصمم):** Execution of tasks, sprint work, code implementation, client follow-ups, and documentation.
5. **Guest / Observer (مراقب / عميل):** Optional read-only access to specific project progress boards.

## 4. Key Workflows in Novixa WorkOS

1. **Product Sprints:** Tracking feature backlog and roadmap items for *Novixa Aqar* and *Muhajim*.
2. **Client Deal to Project Pipeline:** Moving an inbound lead through CRM stages (Lead → Qualified → Proposal → Negotiation → Won), automatically creating a delivery project with milestone templates upon winning.
3. **Daily Engineering Routines:** "My Day" and "My Tasks" views allowing engineers to prioritize their focused daily commitments.
4. **Knowledge Sharing:** Standard Operating Procedures (SOPs), deployment playbooks, and architectural decision records (ADRs) authored and linked directly to relevant systems.
