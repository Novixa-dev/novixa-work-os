## 🔒 نتائج مراجعة T3 الأمنية
| البند | الإصلاح |
|-------|---------|
| مسار `notifications/{id}/read` كان يستدعي دالة غير موجودة (خطأ 500) | تصحيح اسم الدالة + اختبار ملكية الإشعار |
| محارف LIKE (`%` `_`) غير مُهرَّبة في البحث | `App\Support\Like` مطبّق على كل نقاط البحث |
| غياب ترويسات الأمان | Middleware `SecurityHeaders` (nosniff, X-Frame-Options, Referrer-Policy, HSTS على HTTPS) |
| رموز Sanctum بلا انتهاء | انتهاء افتراضي 480 دقيقة (`SANCTUM_TOKEN_EXPIRATION`) |
| `remember=true` دائم عند الدخول | إزالته |
| كلمة مرور جديدة ضعيفة (8 أحرف) | 10+ مع أحرف كبيرة/صغيرة وأرقام + إلغاء بقية الرموز عند التغيير |
| امتداد المرفق من العميل | استخدام `extension()` المُستنتج من المحتوى |

**مخاطر معروفة (موثّقة):** الواجهة تخزّن الرمز في `localStorage` (يُفضَّل كوكي HttpOnly عبر Sanctum SPA) — مُدرجة كتحسين لاحق.
